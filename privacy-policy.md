# statesdex-privacy-policy
StatesDex Privacy Policy 

This Privacy Policy explains how StatesDex ("the Bot", "we", "us", or "our") collects, uses, and handles data when you add the Bot to your Discord server or interact with it. We respect your privacy and are committed to complying with the Discord Developer Policy and developer terms.

# 1. Data StatesDex Collects
To function properly, the Bot accesses specific information through the Discord API. The data that is collected are as follows:
- Discord user IDs, usernames, display names and profile pictures
- Discord server IDs and channel IDs
- Message Content (it is briefly processed when using text-based admin commands, but message content is not stored.)
- Server member counts

# 2. How StatesDex Uses Your Data
StatesDex only processes your data to execute the bot's features. The ways StatesDex uses your data are as follows:
- Discord user IDs are the way StatesDex stores your bot data (owned states, completed trades)
- Discord server IDs and channel IDs are used to see where states were caught.
- Message Content is only used for text-based commands, which are exclusive to bot staff members.
- Server member counts are used to determine: a. if a state can successfully spawn and b. how fast it will spawn

# 3. How Your Data Is Stored
StatesDex is hosted locally on the developer's computer, so all collected data is always stored within the device or the bot's database, and will never leave it.

# 4. Data Sharing
StatesDex does not and will never sell, share, trade, rent or monetize your data. It is not shared with any external parties and is stored strictly within the bot's database. Message content is not stored by the bot. Only the developer and staff team has access to it.

# 5. Data Deletion
If you do not want your data stored within the bot's database, you can request your data to be deleted by contacting the owner. After a data deletion request, your data would be deleted within a reasonable timeframe.
